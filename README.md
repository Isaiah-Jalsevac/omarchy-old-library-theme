# Old Library

A warm, dark Omarchy theme inspired by old libraries and well-loved books. Espresso backgrounds and aged-paper text are paired with muted moss, slate, oxblood, and antique-brass accents. Includes three open-source library photographs as backgrounds.

## Install

```sh
omarchy theme install https://github.com/Isaiah-Jalsevac/omarchy-old-library-theme
```

## Palette

- Background: espresso brown (`#1c1915`)
- Foreground: aged paper (`#e6dccb`)
- Accent: antique brass (`#c4a36a`)
- Supporting accents: muted moss, slate, and subdued oxblood
